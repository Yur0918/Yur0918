### 朱佳皓 · AI 产品经理

金融风控背景的 AI 产品经理，做企业级智能体的工程化落地。

---

**三个代表作品**

- **[dify-workflow-dsl-skill](https://github.com/Yur0918/dify-workflow-dsl-skill)** —— Dify 工作流 DSL 导入前校验器：在 DSL 进 Dify 之前先做结构 / 引用 / 类型的确定性校验，不通过就不放行。
- **[dsh-user-addons](https://github.com/Yur0918/dsh-user-addons)** —— DSH Web 插件：文件上传 / 会话归档 / 模型与 token 用量看板，不改 DSH 核心文件。
- **[dsh-sidepanel](https://github.com/Yur0918/dsh-sidepanel)** —— DSH 右侧面板：Artifacts 视图（归档会话产物）+ fork 子智能体的 Side chat。

**其余作品**

- [dsh-soul](https://github.com/Yur0918/dsh-soul)：人设 / 记忆 / 审计插件，含确认槽与 append-only 审计。
- [headless-frontend-check](https://github.com/Yur0918/headless-frontend-check)：把「前端看着没问题」变成可断言的浏览器校验。
- [mail-batch-sender](https://github.com/Yur0918/mail-batch-sender)：本机使用的邮件批量发送小工具。

---

**技术栈**：Dify / Agent 工作流 / TypeScript / Python

**我关注的一点**：核心是**知道哪一段不该交给 LLM** —— 能用确定性校验和人工兜底的地方，就不交给模型随机决定。

**学习参考（非本人作品）**

- [dsh-market](https://github.com/Yur0918/dsh-market)、[awesome-dsh-plugin](https://github.com/Yur0918/awesome-dsh-plugin)：上游项目的学习用 fork，非本人作品。
